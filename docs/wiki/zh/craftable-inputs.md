# 样板原料标记

[手册目录](../README.md) · [项目首页](../../../README.md) · [English](../en/craftable-inputs.md)

> [使用手册](../README.md) / [AE 网络与自动化](../README.md#ae-网络与自动化)

在样板终端编写配方时，原料若在当前网络中已有合成样板，其右上角显示 **＋**；悬停可查看说明。支持物品、流体及共用原生界面的扩展、无线样板终端。

不需要下单优化元件。有标记表示存在样板，不代表整条合成链一定有足够材料。
